# Donation Landing Page

A static donation website with a payment link and contact page.

## What is included

- HTML, CSS, and JavaScript where present; no application build step.

## Getting started

Open `index.html` in a modern browser. Keep the repository folder structure intact so relative links and assets resolve.

## Repository guide

- `README.md`
- `contact.html`
- `image.jpeg`
- `images.jpeg`
- `index.html`
- `sparkback.jpg`
- `style.css`

## Limitations and reproducibility

Payment is delegated to the linked external provider. This repository does not contain a payment-processing backend, transaction verification, or a working contact-message service.
